# Snapcraft listing assets

Title: Spotipy Visualizer

Summary: Spotify now playing display with album art, controls and a clock

Paste `description.txt` into the store Description field. The same text is in
`snapcraft.yaml` for future builds.

Upload images in this order:

1. `1.png` — player screenshot, resized from the root `1.png`.
2. `2.jpeg` — physical display photo, resized from the root `2.jpeg`.

Both exports use a maximum 1600-pixel longest edge, preserve the original
aspect ratio and full framing, and have metadata removed. Originals are retained.
The photo shows an example hardware setup; hardware is not included.

Screenshot requirements checked against Canonical's listing guidance:
https://forum.snapcraft.io/t/store-listing-and-branding/16397

PNG/JPEG, at least 480 × 480, no larger than 3840 × 2160, aspect ratio
between 1:2 and 2:1, and less than 2 MB per image.

These files are prepared locally; upload them through the Snapcraft listing page.
